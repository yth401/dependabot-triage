# 出力の形

## まとめ（最初に書く）

表を 2 つに分けて示す。0 件の行・列も省かずに書く。

**今回の判定**：要否（行）とこのプロジェクトでの深刻度（列）のマトリクス。不要には深刻度がないので「−」で数える。

| 要否 ＼ 深刻度 | 緊急 | 高 | 中 | 低 | − | 計 |
|---|---|---|---|---|---|---|
| 要対処 | 1 | 0 | 1 | 0 | 0 | 2 |
| 不明 | 0 | 1 | 0 | 0 | 0 | 1 |
| 不要 | 0 | 0 | 0 | 0 | 2 | 2 |
| 計 | 1 | 1 | 1 | 0 | 2 | 5 |

**判定しなかったもの**：件数だけ。起票済は、dependabot-triage の Issue（要対処・保留とも）が開いているもの。期限は Issue を見ればわかるので書かない。

| 分類 | 件数 |
|---|---|
| 起票済 | 4 |
| 閾値で対象外 | 4 |

- 保留の期限切れで判定し直したものは、今回の判定の表に入れる
- 判定する範囲を区切った（check の手順 6）ときは、判定しなかった件数を 1 行足す
- KEV を取ってこられなかったときは、その旨を 1 行足す

## 1 件ごと

要対処 → 不明 → 不要 の順に並べる。同じ要否の中では、このプロジェクトでの深刻度が高い順にする。

```
#42 example-web-framework（package-lock.json） 3.1.4 で修正
  GHSA-xxxx-xxxx-xxxx / CVE-2026-00000 ・ Dependabot：high ・ CVSS 8.1 ・ EPSS 2.3% ・ KEV なし
  <勧告の要約>

  対処の要否：要対処
  このプロジェクトでの深刻度：中（Dependabot：high → 社内からしか開けないため 1 段下げ）
  対処期限：2026-11-26

  根拠
    0. 影響を受けるバージョンか：入っている（package-lock.json で 3.1.0）
    1. 脆弱な機能を使っているか：使っている（直接の依存。`renderToString` を src/server/render.ts:12 で呼んでいる）
    2. 攻撃が成り立つ条件：そろう（ログインした利用者が細工したリクエストを送れる。社内からしか使えないが、利用者の PC が乗っ取られた場合はその PC から攻撃できる）
    3. どこで動く依存か：本番、直接の依存
    4. 悪用状況：KEV なし、EPSS 2.3%
    5. 直せるか：パッチ版の更新ですぐ直せる
    6. プロジェクトの事情：guidance.md「管理画面は社内ネットワークからしか開けない」

  やること：example-web-framework を 3.1.4 以上に上げる
```

| 項目 | いつ書くか | 中身 |
|---|---|---|
| 見出し | 必ず | アラート番号、パッケージ、マニフェスト、修正版（なければ「修正版なし」） |
| Dependabot の評価 | 必ず | GHSA / CVE、深刻度、CVSS、EPSS、KEV（あり／なし／照合できず） |
| 対処の要否 | 必ず | 要対処／不要／不明 |
| このプロジェクトでの深刻度 | 要対処・不明 | 緊急／高／中／低と、上げ下げの経緯 |
| 対処期限 | 要対処 | `YYYY-MM-DD`、または「期限なし」 |
| 根拠 | 必ず | 観点ごとの答え（[判定の基準](criteria.md) の「根拠の書き方」） |
| やること | 要対処 | 何をどのバージョンに上げるか、回避策 など |
| 人が確かめること | 不明 | 何がわからなかったか、何を確かめれば決められるか |
| 閉じる理由とコメント案 | 不要 | 下の表 |

## 閉じる理由の選び方（不要のとき）

[判定の基準](criteria.md) の「1 段目」の表のとおりに選ぶ。

| 不要の理由 | 閉じる理由の区分 |
|---|---|
| 実際のバージョンが影響の範囲に入っていない（Dependabot の誤検知） | `inaccurate` |
| 脆弱な機能を使っていない | `not_used` |
| 使っているが、攻撃が成り立たない | `tolerable_risk` |

コメント案は 280 文字以内で、何を根拠に不要としたかを書く。末尾に `（dependabot-triage）` を付ける。KEV に載っているものは、コメントにもそのことと根拠を書く。

例：`SSR を使わない静的サイトのため、脆弱な機能に届かない。renderToString などの呼び出しはコードにない（dependabot-triage）`
